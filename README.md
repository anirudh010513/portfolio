# Portfolio — Anirudh Baradwaj

Premium personal CV/portfolio website built with **React 19 · TypeScript (strict) · Vite · Tailwind CSS · Framer Motion**.

🔗 **Live:** https://anirudh010513.github.io/portfolio/

## Features

- Apple-inspired minimal design, dark mode by default with light-mode toggle
- Self-hosted variable fonts (Inter, Space Grotesk, JetBrains Mono) — no external requests
- Sections: Hero, About, Education, Experience, Skills, Projects, Certifications, Contact
- Mouse-tracked spotlight cards, scroll reveals, parallax hero, skills marquee, scroll progress bar
- Lazy-loaded below-fold sections for fast initial load
- Printable resume (`/resume.html`), SEO meta + Open Graph + JSON-LD, generated OG image
- WCAG-minded: skip link, focus rings, ARIA labels, reduced-motion support
- Auto-deploys to GitHub Pages via GitHub Actions on every push to `main`

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # strict TypeScript check + production build
npm run preview  # preview the production build
```
